# Dice-Duel-Game

This is a simple Java console game where you play against the computer

Both you and the computer roll a random number between 1 and 6

The player with the higher number wins the round

When you start the program it asks if you want to play

If you enter 1 the game begins and both players roll

Your number is printed followed by the computer's number

If your number is higher you win the game

If the computer's number is higher you lose the game

If both numbers are the same it's a draw and you are invited to play again

If you enter 2 the program thanks you and exits

All game logic is written in the Main.java file

This game is made for practice and fun using basic Java features like Random and Scanner
